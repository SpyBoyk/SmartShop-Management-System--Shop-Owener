# SmartShop-Management-System--Shop-Owener

Modern Smart Retail POS & Shop Management System built with **Vue 3, TypeScript, Vite & Tailwind CSS**.

## ✨ Key Features

- 📷 **Live Continuous Barcode / QR Scanner**: Powered by `@zxing/browser` with full-HD autofocus and anti-duplicate debounce.
- 🛒 **D-Mart Style POS Billing**: Instant scan-to-bill with automated quantity increments (`+`) for repeat items.
- 🌐 **Dynamic Open Product APIs**:
  - **Open Food Facts**: Food and beverages
  - **Open Beauty Facts**: Cosmetics and personal care
  - **Open Products Facts**: General retail merchandise
  - **UPCitemdb**: Electronics & consumer goods
- 💰 **Cashier Total & Static Payment QR**: Real-time grand total announcement box and integrated UPI / Store Payment QR display.
- 🏬 **Multi-Shop Mode**: Pre-configured for Supermarkets, Pharmacies, and Mobile Gadget stores.
- 📱 **100% Mobile Responsive**: Compact, touch-friendly UI conforming to the TailAdmin design system.

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```
